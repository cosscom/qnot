title: Install with shadcn
description: Add the coss ui query builder or any example to your project as source, with one command.
---

The site is a [shadcn registry](https://ui.shadcn.com/docs/registry). `shadcn add` copies trawlnet's
coss ui query builder, or a whole example, into your project as source you own, installs the npm
packages it needs (`@trawlnet/core`, `@trawlnet/react`, `lucide-react`), and pulls the
[coss ui](https://coss.com/ui) components it uses from coss's own registry.

## Before you start

Your project needs Tailwind CSS v4 and a `components.json`. If you don't use coss ui yet, set it up
first:

```sh
pnpm dlx shadcn@latest init @coss/style
```

Files land under `components/trawlnet/` (your `components` alias), and their imports are rewritten
to your aliases. Everything installed from this registry is MIT licensed.

## The query builder

<RegistryInstall name="query-builder" />

```tsx
'use client';
import { createQueryStore, defineFields, f } from '@trawlnet/core';
import { useState } from 'react';
import { CossQueryBuilder } from '@/components/trawlnet/query-builder';

const fields = defineFields({ name: f.text(), age: f.number({ min: 0 }), plan: f.enum(['free', 'pro']) });

export function Filters() {
  const [store] = useState(() => createQueryStore({ fields }));
  return <CossQueryBuilder store={store} showLock />;
}
```

## Other UI kits

The builder also comes in shadcn/ui, MUI, Mantine and plain-HTML variants, the ones on the
[UI kits](/kits) page. Each one installs `query-builder-core`, the kit-agnostic builder they share
(`components/trawlnet/kits/shared`), plus the kit's own controls:

| Item | Install into | Brings |
|---|---|---|
| `query-builder-shadcn` | a Radix-based shadcn/ui project (`pnpm dlx shadcn@latest init --base radix`) | the shadcn/ui components it uses, in your project's style |
| `query-builder-mui` | any React project | `@mui/material`, `@mui/icons-material`, Emotion |
| `query-builder-mantine` | any React project | `@mantine/core`, `@mantine/hooks`, and Mantine's stylesheets for its components |
| `query-builder-headless` | any Tailwind project | nothing else: plain HTML to restyle |

<RegistryInstall name="query-builder-mui" />

```tsx
'use client';
import { createQueryStore } from '@trawlnet/core';
import { useState } from 'react';
import { QueryBuilder } from '@/components/trawlnet/kits/mui';
import { fields } from './fields';

export function Filters() {
  const [store] = useState(() => createQueryStore({ fields }));
  return <QueryBuilder store={store} />;
}
```

<Callout type="info" title="shadcn/ui on Base UI">
  `query-builder-shadcn` is written against the Radix-based shadcn/ui components. Projects using a
  Base UI style (`"style": "base-…"` in `components.json`, which plain `shadcn init` can create) get
  type errors; use the coss ui builder there, which is built on Base UI.
</Callout>

<Callout type="warn" title="One component style per project">
  The coss ui builder (`query-builder`) and the shadcn/ui variant (`query-builder-shadcn`) both
  install their components into `components/ui`, and their components share names (`select`,
  `button`, `tooltip`…). Pick one of the two per project; mixing them overwrites one with the other.
</Callout>

## An example

Every [example](/examples) is a registry block: the page shows its full source and the command to
install it. Each example exports a `Demo` component:

<RegistryInstall name="product-filters" />

```tsx
import { Demo as ProductFilters } from '@/components/trawlnet/examples/product-filters';

export default function Page() {
  return <ProductFilters />;
}
```
